**📊 Sales & Performance Dashboard (Excel)**
**🔍 Project Overview**

This project is an interactive Sales & Performance Dashboard built using Microsoft Excel.
It provides a clear view of sales, tax, quantity, customer behavior, and product performance using dynamic charts and slicers.

The dashboard helps stakeholders quickly understand business performance and make data-driven decisions.

🎯 Key Objectives

Track total sales, tax, and quantity

Analyze payment methods used by customers

Compare member vs normal customers

Identify top-performing product lines

Provide an interactive experience using slicers
